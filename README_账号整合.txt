账号整合测试副本（工作台_账号整合）说明
================================================

这是什么
--------
真实工作台（工作台_online, 8765）的本地副本，把「账号 + 配额 + 数据隔离」
接进了真实前台：用测试账号登录真实界面、真实上传、真实出片，配额实时扣减。
生产台（8765 / 线上 / 内网）完全不受影响。

怎么启动
--------
双击 start_8790.bat（纯本地 127.0.0.1:8790，不对外）。
浏览器打开 http://127.0.0.1:8790/ —— 未登录会被自动带到登录页。

设计要点
--------
- 账号来源可插拔：providers.AccountProvider，本地用 LocalFixtureProvider；
  公网阶段换 MagentoRestProvider（占位已写好），业务层零改动。
- 数据隔离复用既有 studio_sid：账号会话下 sid = sha256(customer_id)，
  同客户跨会话共享项目，跨客户互不可见（403）。
- 配额：QuotaLedger（sqlite3，_ledger/ 目录，绝不放会被发布重置的 data/）。
  出片类端点提交时预占并按 200 扣减、失败释放；预览类端点不计费。
  已知口径：额度在「任务被接受」时扣，异步渲染若后来失败不自动退
  （本地测试口径，公网阶段应改为按任务终态结算）。
- 已知限制：登出只是清浏览器 Cookie，签名 token 本身未做服务端吊销
  （重放旧 token 在 30 天内仍有效）。公网阶段应改短时效 + 服务端会话表。

红线（务必遵守）
----------------
1. 本副本 config.json 含真实 AI 密钥 —— 绝不可发布上线 / 提交 git / 拷到公网机。
2. fixtures.py 只存哈希，不含任何真实客户 PII / 口令；真实口令永不落盘。
3. 出片配额与账号库都在 _ledger/，发布/重装不会重置它；但也因此
   手工删 _ledger/ 即可清零账本（或用 admin 调 POST /api/reset）。
